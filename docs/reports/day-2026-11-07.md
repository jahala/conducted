## Findings from review

The lead's review of builder work changed these before merge:

- **CLOUD-14:** one sandbox could ask the Mac to run a command under another chat's "Yes for this session". Each cloud tunnel now carries its own host, and the app refuses a mismatch. The Mac's approval card also cancelled the agent's own open card; it now covers it, and the agent's card comes back when it closes.
- **CLOUD-15:** the status, meters, cost and Restart were an inline strip. Conductor shows them in a popover from the header's workspace button, so they moved there. The Environment row says "Cloudflare", because "Conductor Cloud" is the other company's brand.
- **CLOUD-09's finish:** the builder added up and down ordering for forwarded ports, which Conductor does not have. It was reverted; Conductor's ordering belongs to the Preview URLs list (#454). Two copies of the preview URL call became one, so a Worker's refusal now shows its own reason.
- **CLOUD-12:** a builder proposed leaving the whole row out (D115). That was refused, because opening a cloud workspace in a local editor is a Conductor feature; the row is being built instead.
- **The catalogue click:** since #428 the shots and harness jobs failed on every PR, because the catalogue's click sent a click count of 0. Fixed in #452. The PR waiter had watched only the required checks, so #449 merged through that red; it now reports every check.
- **Merging together:** CLOUD-09's finish and CLOUD-15 each added a `CloudIcon`, each green alone; merging main into CLOUD-15 before its merge caught the clash.
- **#457** found six real bugs while drawing new catalogue states. The worst: a pull request an agent opened could not be merged or synced, because the actions needed a number only manual linking set.
