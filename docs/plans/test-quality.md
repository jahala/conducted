# Test quality plan for Conducted

This plan turns the five test reviews of slices 1 and 2 (step 1) into work the build can run. Nothing was run to make it. Facts the conductor read in the code are marked "confirmed". Everything else is "reported", meaning a reviewer found it by reading, and it still needs its failing test to prove it.

Report keys used in brackets. Finding ids are from each report's findings section unless a section number is given.

- cs = [core-services](../reports/test-quality/core-services.md), cp = [core-platform](../reports/test-quality/core-platform.md), ui = [ui](../reports/test-quality/ui.md), sc = [sidecar](../reports/test-quality/sidecar.md), rs = [rust-scripts-layers](../reports/test-quality/rust-scripts-layers.md)
- cov = [coverage, 2026-11-05](../reports/test-quality/coverage-2026-11-05.md), todo = the step 1 fix list, which the slice 2 step 1 pull request carries
- "Step 1" is slice 2 step 1 (landed, CI not run). "Step 2" is the next one.

## 4. The work, in batches

A test that fails today because the product is broken lands in the same change as its fix, or is the acceptance test of the feature build that owns the fix. There are no known-red marks (D055).
